GIFTMAGZZ FRONTEND

1. Edit app.js:
   - For local development, API_BASE_URL should be http://localhost:5000/api
   - Set WHATSAPP_NUMBER to your international number with digits only, e.g. 919876543210

2. Serve the folder (do not open index.html with file://):
   npx serve .
   Open the URL printed by the command.

3. For a deployed website, change API_BASE_URL in app.js to:
   https://YOUR-BACKEND-DOMAIN/api

Frontend features:
- Royal navy, white and blue design
- Slide-in signup/signin panel
- Theme and page selection
- Automatic server-side price calculation
- Order submission to backend
- Confirmation and WhatsApp pre-filled message
